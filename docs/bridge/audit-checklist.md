# Audit Checklist

Before companion work is complete:

- [ ] Tests cover expected and rejected behavior.
- [ ] No production private key custody is introduced.
- [ ] Protocol behavior matches the authoritative `protocols/contracts/v1` artifact.
- [ ] CLI output is deterministic where required.
- [ ] Error messages are actionable.
- [ ] Docs explain trust boundaries.
- [ ] Dependency licenses are compatible with MIT.
