# Rust QR worker: fixed public host experiment

Three original13949 envelopes were decoded by real rqrr0.11.0 and returned byte-for-byte: get-public-key request98B, sign request259B and get-public-key response198B. The611B sign response reached the fixed writer cap, refused the next one-byte append after512 staged bytes, exited42 and published **zero stdout**. The blank image exited20/noQR with zero stdout. These are author observations pending distinct review of this exact source.

[First198](first-198/summary.json) passed before dependent execution. [Focusedfive](focused-5/summary.json) and [one stablefive](stable-5/summary.json) then passed on unchanged source142135cd. All five final workers had kernel SID/PGID equal their own PID before parent prlimit/readback and any control/image transfer; actual status and descriptors settled before reuse. Parent session/group/limits/descriptor set stayed unchanged, with one final thread. Exact source, binary, command, raw byte and per-case bindings are in [result.json](result.json).

The [Rust binary](src/main.rs) receives only G plus the original240×240 RGB888 bytes on stdin. It calls setsid before G and does image/detector work after the gate. These fixed images have equal RGB channels; direct channel luminance is used without a camera/color claim. Real prepare_from_greyscale → detect_grids → decode_to performs detection/error correction/decoding. No expected envelope, key, signature operation or fixture filename is embedded in the worker. A fixed512-byte Write implementation checks before each append. Upstream partial-decode writes stay staged; stdout is written only after successful complete decode. No decode-to-String intermediate is used.

The [new supervisor](controller.py) imports exact corrected06d helpers and adapts the same finite process mechanisms. [Correspondence](supervision-correspondence.json) distinguishes reused helpers from adapted source. It uses plain posix_spawn, bounded kernel-identity rendezvous, unchanged AS256MiB/CPU1,2s/wall8s/cleanup4s/core0, separate512B stream retention and4096B chunks. Final result predicates sample monotonic time after acquired wait and I/O settlement. Signals target explicit owned positive PIDs only; unknown status quarantines. Original22 fault cases and the deadline regression remain historical on06d; they are **not** relabelled as tests of this adapter.
